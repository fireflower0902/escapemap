## 검증 근거

- `doors/sync_sinbiweb_db.json`, `zone/sync_ccescapezone_db.json`: 7일치 읽기 검증.
- `publish-results.json`: 실제 Supabase 저장 검증 결과.
- 접근 제한, 공사 중, 공식 예약처 미확인은 서로 다른 상태로 보관한다.
- 전체 미수집 목록은 `../uncrawled-review-2026-11-15/README.md`에 보존했다.

실제 DB 재조회: 더도어즈 6개 영업일·6개 테마·312개 슬롯, 춘천 이스케이프존 7개 영업일·5개 테마·350개 슬롯. 더도어즈의 당일 시간은 모두 지나 수집기에서 제외되었으며, 없는 시간표를 빈자리로 생성하지 않았다.

추가한 두 카페의 DB engine·공식 예약 URL과 현황판용 디렉터리도 갱신했다. 변경 전 값은 `metadata-update.json`에 보존했다.
