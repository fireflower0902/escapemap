# 미구현·보류 크롤러 재검토 (2026-11-21)

## 범위와 확인 수준

- 운영 카페 405개, 시작 시 정기 수집 대상 307개, 대상 외 98개를 목록화했다.
- 기존 검토에 포함된 공식 URL 49개 재확인: HTTP200 32개, 연결 실패 15개, 그 외 응답 2개. 이미 수집을 복구한 카페의 URL도 일부 포함한다.
- 홈페이지 HTTP200은 시간표 수집 성공을 의미하지 않는다. 아래 기존 사유는 11월16일 근거이며, 이번 재확인과 구별했다.

## 이번 수정과 저장 검증

- 오아시스 뮤지엄: 공식 JavaScript는 getSchedule의 null을 마감 없음으로 처리한다. 수집기의 null 오류를 수정하고 콜렉터 하우스(17번)는 홈에 소개되지만 공개 예약 페이지가 없어 제외했다.
- 예약 페이지가 공개된 테마 5개를 등록했고, 공개 시간표는 4개 테마·183개 시간대(예약 가능110 / 마감73)였다. 나머지 1개 테마의 빈 시간표를 임의 생성하지 않았다.
- 11월21일~27일 7일 모두 Supabase cafe_date_checks 성공.
- 더트랩 수유: 자체 시간표는 네이버 예약 안내로 전환됐다. 네이버 공개 연결 HTTP429로 현재 예약 사업자 확인 보류.
- 레다스퀘어: 아바타 테마 목록은 정상, 확인한 11월22일 시간표는 공백. 전체 매진/폐업으로 단정하지 않았다.
- 더코드: 기존 공식 도메인이 이번 조회에서 DNS 연결 실패.
