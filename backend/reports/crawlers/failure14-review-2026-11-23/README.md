## 처리 우선순위

1. GitHub에서 유효한 HTML 대신 무엇을 받는지 진단 강화: 최종 URL(비밀 query 제외), Content-Type, 크기, 예약 구조 존재 여부, 실제 응답 날짜를 기록. 정상 HTML과 오류 안내를 구분하고 날짜 검증은 유지.
2. 이스케이퍼스 CSRF 파싱은 HTML 파서로 속성 순서에 독립하도록 개선. 이것만으로 GitHub 접근 문제가 해결된다고 가정하지 않음.
3. 셜록홈즈 수원인계점의 공식 네이버 예약처 확인 후 적합한 수집기로 연결. 영업 종료로 취급하지 않음.
4. 리멤버 공통 API는 간격을 둔 제한적 재시도와 장애 사유 표시 검토. 실패 응답을 정상 데이터로 게시하지 않음.
