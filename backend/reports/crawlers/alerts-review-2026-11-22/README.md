## 변경

1. 수집 제한 시간 초과에도 새 JSON 결과를 생성. `published: false`와 `timeout` 상태를 보존하고 사이트 실패로 분류.
2. 시간 초과 상태의 DB 저장에 실패하면 `storage` 오류로 기록하고 시스템 실패 유지. 원본 연결 문자열은 출력하지 않음.
3. 개별 읽기 전용 검증 워크플로는 사이트 검증 실패를 경고로 기록. 실행 요약에 통과/확인 필요 개수와 사유를 표시하고 이번 실행의 결과 파일만 7일간 보관.
4. CLI 기본 엄격 검증은 유지. GitHub 워크플로에서만 명시적인 `--allow-site-failures` 사용.
5. DB·코드 오류, 자식 실행 결과 누락, 분할 결과 누락/중복, 전체 게시율 90% 미만은 기존처럼 실패 유지. 실패한 카페를 성공으로 게시하지 않음.
