## 검증 범위와 자료

- `official-url-checks.json`: 이번21곳의 기존 URL 실응답. 지도 URL 응답은 영업·예약 가능의 증거가 아님.
- `directory-*-leads.json`, `additional-name-search-leads.json`, `gangnam-booking-leads.json`: 공개 디렉터리·검색에서 얻은 단서. 단서만으로 수집 연결이나 폐업 판정하지 않았음.
- `*-identity.json`: 실제 네이버 공식 예약 페이지의 공개 사업장 이름·주소·placeId.
- `*-github.json`, `*-local-publication.json`: 지점별 실제 검증 및 게시 결과.
- `production-api-verification.json`: 운영 API에서3곳 최신 시간표 노출·야탑 제외 확인.
- `lotte-*.json`: 공식 경로·공개 상품·권한 없음 안내. 로그인/실제 예약/결제 없음.

언리미티드는 제3자 목록에 전화예약 안내가 있지만 최신 공식 근거가 미확정이므로 전화 전용이나 폐업으로 확정하지 않았습니다. 나머지 연결 실패 업체도 폐업으로 일괄 제외하지 않았습니다. 알카트래즈·오늘탈출은 사용자 요청대로 이번 접근·검토 대상에서 제외했습니다.
