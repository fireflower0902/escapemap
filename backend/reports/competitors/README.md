## 비교 기준

- Unicode·대소문자·띄어쓰기·기호와 일반적인 방탈출 표기를 정리해 이름을 대조합니다. 지점 번호는 유지하고, 우리 DB의 지점 필드가 있는 경우 끝의 점 표기 유무를 대조합니다.
- 유사한 이름이나 주소 일치는 확인 후보로 남기며 자동으로 합치지 않습니다. 공식 지점 안내로 수동 확인한 별칭만 기존 카페 ID에 연결합니다.
- 테마는 이름이 연결된 동일 카페 안에서만 대조합니다. 카페 연결이 불분명하면 테마를 누락으로 확정하지 않습니다.
- 경쟁사에 없는 우리 항목은 수집 범위가 다를 수 있어 부재를 확정하지 않습니다.
- 경쟁사 목록을 우리 운영 DB에 자동 추가하지 않았습니다.
