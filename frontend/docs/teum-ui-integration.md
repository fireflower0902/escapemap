## 실제 데이터 및 기능

- `/`: 실제 조회된 예약 가능 테마 미리보기, 지역 선택, 퀴즈 진입.
- `/search`: 기존 `/api/search`와 Supabase 연동. 전국 지역·날짜·심야 시간 범위·카페/테마명·예약 가능 조건 검색.
- 실제 예약 가능 시간은 공식 예약처 링크로 이동하며 앱에서 예약을 제출하지 않는다.
- 최신 수집 시각을 표시하며, 시간표가 없는 상태를 마감으로 추정하지 않는다.
- `/my`: 실제 테마 ID로 찜·방문 기록을 이 브라우저의 localStorage에 저장. 계정 간 동기화 기능은 아님.
- `/quiz`: 실제 풀 수 있는 샘플 숫자 추리 3문제, 정답·오답·힌트·다음 문제.
- `/online`, `/community`, 빈자리 알림: 준비 상태를 명시. 예시 게시물이나 가짜 예약 데이터를 운영 데이터로 표시하지 않는다.
- `/dev/crawlers`, `/dev/comparison`, `/login` 경로는 유지한다.

- 데스크톱 1440px, 모바일 390px/320px, 태블릿 768px: 문서 가로 넘침 없음.
- 390px 시간표 5열 및 34px 버튼 높이, 320px 시간표 4열.
- 실제 부산 25개 카페·110개 테마, 다음 날 강남 45개 카페·148개 테마 검색 확인.
- 실제 테마의 찜·방문 기록이 새로고침 뒤에도 유지됨.
- 공식 예약 링크의 외부 이동 속성 및 URL 확인. 실제 예약 제출은 하지 않음.
- 잘못된 시간 범위 안내·퀴즈 정답/오답 확인. 브라우저 실행 오류 없음.
- 프런트 테스트 17개와 TypeScript 검사 통과. 별도 `.next-verify` 디렉터리에서 프로덕션 빌드 통과.

로컬 확인: http://localhost:3000 및 http://localhost:3000/search

Supabase의 기존 90분 신선도 기준을 유지한다. 새로고침은 저장된 최신 예약표를 조회하며 원본 사이트의 재크롤링을 직접 실행하지 않는다. 수집 주기·자동 실행 상태는 별도 크롤러 설정을 따른다.
